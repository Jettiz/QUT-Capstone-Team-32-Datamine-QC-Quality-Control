# QUT-Capstone-Team-32-Datamine-QC-Quality-Control
The repo for the Datamine QC Quality Control AI Solution

For the moment, there isn't executables until further on in the project.


## Organisation:
- config
  - Config Files.
- data
  - processed
    - Cleaned up data for both model training and model testing.
  - raw
    - Raw data.
- notebooks
  - Notebooks goes into this file.
  - Archive
    - Stores old archived notebooks.
  - Model
    - Model notebooks
- src
  - detectors
    - Detection Model Logic.
  - visualisers
    - Model visualisation logic.

## File Naming:

Files should usually start with (If tag is applicable)
> <SAMPLETYPE>_<attribute>_<tags>.filetype


for example
> MATRIX_visualize.py
> DATA_loader
> visualiser.py

Note: all names and data should be consistent with Standard Australian English spelling conventions.
