Load a Sample

Pick a CCLAS CSV export (e.g. data/raw/ResultSet.csv or one of the files under data/samples/). The local server loads it with src/data_loader.py, validates it with src/data_validator.py and runs the real QC analysis for the connected detectors (currently Control / LCS). Nothing leaves your computer.

This page was opened directly from disk, so the real analysis cannot run. Start the local server with python poc/server.py and open http://localhost:8000.
